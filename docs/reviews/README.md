# BAC 论文背景综述

本目录保存围绕 **Human–AI Contribution Provenance（人机协作贡献溯源）** 的首轮文献综述，服务于 bensz-auto-contribution 论文的 introduction、discussion 与立项依据。

核心交付：

- `human_ai_contribution_provenance_review.pdf`：可直接阅读的中文综述。
- `human_ai_contribution_provenance_review.docx`：Word 版本。
- `human_ai_contribution_provenance_review.tex` 与 `human_ai_contribution_provenance_参考文献.bib`：可复编译源文件。
- `human_ai_contribution_provenance_验证报告.md`：字数、章节、引用一致性和摘要覆盖率验证摘要。
- `human_ai_contribution_provenance_工作条件.md`：检索范围、评分/选文、主题结构与已知 workflow workaround。
- `selected_papers_enriched_human_ai_contribution_provenance.jsonl`、`evidence_cards_human_ai_contribution_provenance.jsonl`：供后续写作或研究设计复核的结构化证据。

综述的中心缺口是：现有 Git、AI 水印/检测器、普通操作日志和治理框架分别记录产物来源、操作历史或制度要求，却难以重建人类提出问题、定义约束、选择路径、评价结果和最终授权的认知贡献。BAC 可据此被表述为一种 Human–AI Contribution Provenance 框架，而不是“AI 生成比例检测器”。
