# VS Code 查看器英文默认与中文可选

## 目标与范围

README 与软件主体默认英文，不随宿主语言自动切换；用户可主动选择中文。保留现有只读查看、Git 比较、验证和路径边界。

## 实施

- 将界面、扩展宿主、容器读取及路径错误提示接入共用英中资源；英文作为默认与缺失翻译回退。
- 添加用户级 `bacViewer.language` 设置与面板语言选择器；切换后重新加载查看器并保留搜索、来源筛选与所选事件。
- 英文 README 为主入口，新增中文 README，互相链接；同步发布文档与 CHANGELOG。
- 验证默认英文、中文切换、设置保留、原始数据保真和既有交互；保存改动前后 JPG 并视觉检查。

## 证据边界

仅翻译界面文案。事件摘要、命令、actor 声明、证据、原始 JSON 与外部验证器输出不做翻译，也不写回账本。语言选择是有限枚举，不从账本读取或执行。静态扩展名称、命令与设置说明使用英文。
